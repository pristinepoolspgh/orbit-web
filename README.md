# Orbi for phones

The phone version of Orbi, Jonathan's voice assistant. It talks to the same brain
(the `orbit-brain` function on Pristine Tracker) as the round device.

- Open https://pristinepoolspgh.github.io/orbit-web on your phone.
- Enter a one-time setup code to connect. No keys are stored in this site.
- Hold the button to talk, or tap once and just talk. The keyboard button lets you type.
- Add it to your home screen (Share → Add to Home Screen) and it opens full screen like an app.
