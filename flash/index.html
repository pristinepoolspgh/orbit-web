Install Orby

Puts Orby on a Waveshare board. Pick the one you have. Takes about two minutes.

The watch

Waveshare ESP32-S3-Touch-AMOLED-2.06: rectangular screen, watch band.

This browser can't install it. Open this page in Chrome or Edge on a computer. This page has to be opened over https.

The round one

Waveshare ESP32-S3-Touch-AMOLED-1.75C: round 1.75" screen in a round case.

This browser can't install it. Open this page in Chrome or Edge on a computer. This page has to be opened over https.
  1. Use a computer (Windows or Mac) in Chrome or Edge. Phones and Safari can't do this step.
  2. Plug the board in with a USB-C cable that carries data (a charge-only cable won't show up).
  3. Tap the Install button for your board, pick the port that appears (usually USB JTAG/serial debug unit), and choose Install.
  4. Updating one that's already set up? When it asks to erase, leave erase unchecked: it keeps its Wi-Fi and pairing. Check it only for a brand-new board or a fresh start.
  5. When it's done, unplug and plug it back in. A new board shows a QR code; follow the setup on its screen with your phone.

No port shows up? Unplug, hold the BOOT button while you plug back in, let go, then tap Install again. On Windows, try a different cable or USB port.

Orby needs the screen, microphones and speaker on these two Waveshare boards. A bare ESP32-S3 development board can't run it.
