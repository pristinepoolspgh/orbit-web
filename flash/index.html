Install Orby

Puts Orby on the Waveshare ESP32-S3-Touch-AMOLED-2.06 watch. Takes about two minutes.

  1. Use a computer (Windows or Mac) in Chrome or Edge. Phones and Safari can't do this step.
  2. Plug the watch into the computer with a USB-C cable that carries data (a charge-only cable won't show up).
  3. Tap Install Orby below, pick the port that appears (it's usually called USB JTAG/serial debug unit), and choose Install. Keep it plugged in until it says it's done.
  4. When it says it's done, unplug the watch and plug it back in (or press its PWR button). Orby wakes up and shows a QR code. From there, follow the setup on its screen with your phone.
This browser can't install it. Open this page in Chrome or Edge on a computer. This page has to be opened over https.

No port shows up? Unplug the watch, hold its BOOT button while you plug it back in, let go, then tap Install again. On Windows, if it still doesn't appear, try a different cable or USB port.

Installing erases the watch first, so a watch that was set up before will need its Wi-Fi and setup code again.
